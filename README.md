# Трекер привычек

Простое и эффективное приложение для отслеживания привычек, которое помогает пользователям записывать привычки, устанавливать цели, отслеживать прогресс и визуализировать свою последовательность со временем.

## Функции
- Добавление, редактирование и удаление привычек.
- Отслеживание ежедневного прогресса с системой отметок.
- Визуализация привычек с помощью диаграмм (например, длина серии, процент выполнения).
- Установка напоминаний для привычек.
