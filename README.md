# Трекер привычек

Простое и эффективное веб-приложение для отслеживания привычек, которое помогает пользователям записывать привычки, устанавливать цели, отслеживать прогресс и получать уведомления в реальном времени. Проект построен с использованием современных технологий, обеспечивающих безопасность и масштабируемость.

## Функции
- Добавление, редактирование и удаление привычек.
- Отслеживание ежедневного прогресса с системой отметок.
- Визуализация привычек через графики (например, длина серии, процент выполнения).
- Аутентификация пользователей с использованием JWT.
- Хэширование паролей для обеспечения безопасности.
- Уведомления в реальном времени через WebSockets.

## Используемые технологии
- **NestJS**: Фреймворк для создания серверной части с TypeScript.
- **Prisma ORM**: Инструмент для работы с базой данных PostgreSQL.
- **PostgreSQL**: Реляционная база данных для хранения данных.
- **JWT (JSON Web Tokens)**: Механизм аутентификации.
- **Хэширование паролей**: Использование библиотек (например, bcrypt) для защиты паролей.
- **WebSockets**: Реализация уведомлений в реальном времени.

## Установка
1. Убедитесь, что у вас установлены следующие инструменты:
   - Node.js (версия 18.x или выше)
   - PostgreSQL (версия 14.x или выше)
   - npm или yarn

2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_пользователь/habit-tracker.git
   cd habit-tracker```
3. Установите зависимости
   - npm install
   или  
   - yarn install   
4. Настройте БД
   ```bash
   CREATE DATABASE habit_tracker
   ```

5. Создайте файл .env в корневой директории на основе .env.example (если предоставлен) или используйте следующий шаблон:
```bash
   DATABASE_URL=postgresql://user:password@localhost:5432/habit_tracker?schema=public
   JWT_SECRET=your_jwt_secret_key
   PORT=3000
```
6. Запустит проект с помощью:
   ```bash
   npm run start:dev
   ```
   или
   ```bash
   yarn start:prod
   ```
